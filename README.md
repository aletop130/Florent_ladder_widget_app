# Ladder Widget

An Android home-screen widget and companion app for viewing a live leaderboard.

## Features

- Choose a team on first launch and change it at any time.
- View the selected team's rank, rating, and match count.
- Browse the full leaderboard in the app.
- Refresh data manually or through the widget.

## Build

Open the project in Android Studio, or run:

```powershell
./gradlew.bat assembleDebug
```

The app requires Android SDK 35 and Java 17 or newer.

## Privacy

The selected team name is stored only on the device. The project contains no accounts, credentials, or analytics configuration.
